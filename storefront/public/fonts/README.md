Place the Presicav font file here so the site can load it via `/fonts/presicav-bd.otf`.

Expected filename and location:

- `storefront/public/fonts/presicav-bd.otf`

If you have an attachment named `presicav bd.otf`, download or move it into this directory and rename it to `presicav-bd.otf` to match the @font-face declared in `src/styles/globals.css`.

After adding the file, restart the Next.js dev server (if running):

```
cd storefront
pnpm dev
```

Or run the project's usual dev command (npm/yarn/pnpm as appropriate).
